# Grupo Mbewu — Website institucional

Primeira versão da landing page institucional do Grupo Mbewu, com identidade grafite/branco inspirada na recepção oficial.

## Tecnologias
React 18 + TypeScript + Vite + CSS responsivo + Lucide React.

## Instalação
\`\`\`bash
npm install
npm run dev
\`\`\`

## Produção
\`\`\`bash
npm run build
npm run preview
\`\`\`
A pasta de saída é \`dist/\`. Compatível com Vercel, Netlify ou Coolify (aplicação estática Vite).

## Estrutura
- \`src/App.tsx\` — conteúdo e componentes da página
- \`src/styles.css\` — identidade visual e responsividade
- \`index.html\` — título e metadados

## Antes da publicação
1. Confirmar a lista oficial de empresas (a fotografia da recepção inclui Vuka, além das cinco marcas citadas).
2. Substituir as representações tipográficas das marcas pelos logótipos oficiais.
3. Validar descrições institucionais e ligações dos websites.
4. Confirmar telefone, e-mail e domínio. O e-mail presente no botão de contacto é PROVISÓRIO.
5. Substituir o símbolo de árvore vectorial aproximado pelo logótipo oficial, se disponível.

Não são exibidos números de telefone inventados. O projecto é uma primeira versão de desenvolvimento, não uma publicação final validada.
